# jonathan.fung.dev

This repository contains the source code for my personal website at [jonathan.fung.dev](https://jonathan.fung.dev).

## Setup

Aim was to have a lightweight static site generator using React. This is a very simple take on it, using vite and tailwind. A lot of this was lifted from:

- Vite Playground example: https://github.com/vitejs/vite/tree/c45c984ce88b9f36a61761b4df849b7e8dd8e3ce/playground/ssr-react
- This blog post: https://ogzhanolguncu.com/blog/react-ssr-ssg-from-scratch/
